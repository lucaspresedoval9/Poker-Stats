POKER STATS V2.1 — iPHONE EDITION

Esta carpeta es una PWA (Progressive Web App) preparada para iPhone.

INCLUYE
- Poker Stats V2 con corrección de la gráfica de evolución.
- Manifest completo de instalación.
- Iconos 192, 512 y Apple Touch Icon.
- Modo standalone a pantalla completa.
- Soporte de safe areas de iPhone.
- Service Worker y caché para funcionamiento offline después de la primera carga.
- Importación/exportación JSON para copias de seguridad.
- Aviso de instalación cuando se abre en Safari de iPhone.

CÓMO INSTALARLA EN IPHONE
1. Publica TODO el contenido de esta carpeta en un alojamiento HTTPS.
2. Abre la URL publicada usando Safari en el iPhone.
3. Pulsa Compartir.
4. Pulsa “Añadir a pantalla de inicio”.
5. Activa “Abrir como app” si aparece la opción.
6. Pulsa Añadir.

IMPORTANTE SOBRE LOS DATOS
Los torneos se guardan localmente en el dispositivo/navegador. Usa Exportar periódicamente.
Borrar datos de Safari o eliminar datos del sitio puede eliminar la base local.
La exportación JSON permite restaurarla con Importar.

PARA PROBAR EN ORDENADOR
Un Service Worker no funciona correctamente abriendo index.html con file://.
Sirve la carpeta con un servidor local o publícala por HTTPS.

VERSIÓN
